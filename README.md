# 타로공방 인스타 바이럴 프로젝트

## 캠페인 구조 (한 줄 요약)

## 폴더 구조

```
tarot/
├── README.md          ← 이 파일 (로드맵 + 진행상황)
├── planning/          ← 단계별 기획 문서 (01~12)
├── design/            ← 브랜드 · 캐릭터 · 카드 원본 (인쇄/피드용 고해상도)
└── app/               ← 랜딩페이지 (Cloudflare Pages 배포 루트, 웹용 webp 에셋)
```

## 로컬 실행

```
npx serve app -l 3300   # → http://localhost:3300
```
