### 위치 타겟 (대면 리딩이라 제일 중요)

## 4. 발행 후

- **심사**: 보통 몇 시간~24시간. 승인되면 자동 노출 시작.
- **리젝되면**: 사유 확인 → 대개 카피 문제. "당신 요즘 힘들죠?" 류 개인 속성 단정만 피하면 됨(현재 카피는 안전).

## 5. 성과 보는 법

- **광고 관리자**: 노출·클릭·CPC(클릭당 비용)·랜딩 조회수
- **우리 관리자탭** 📈 통계 → 유입 경로: `meta/paid` 방문 대비 **예약 신청 수** = 진짜 성과(광고→예약)
- **픽셀**: 이벤트 관리자에서 PageView·ViewContent·Schedule이 쌓이는지 확인

## 6. 다음 단계 (데이터 쌓인 뒤)

- 트래픽으로 방문·픽셀 데이터가 충분해지면 → 새 캠페인을 **목표: 판매(Sales)** 로 만들고 최적화 이벤트를 **Schedule(예약 신청)** 로. 광고비가 "예약"에 직접 맞춰짐.
- 단, Schedule은 드물게 일어나는 이벤트라 소규모 지역 광고에선 데이터가 더디게 쌓임 → 중간 단계로 **ViewContent(결과 도달)** 나 **InitiateCheckout(예약 열람)** 최적화도 실용적.
