### 제목 (Headline)
```

```

### 설명 (Description, 선택)
```
오픈 기념 이벤트가 · 예약 30초
```

### 행동 유도 버튼 (CTA)
- **지금 예약 (Book Now)** — 직행 소재이므로 예약 버튼 고정

### 도착 URL — ★ `book=1` 포함 (예약 시트가 바로 열리는 딥링크)
```
https://myoyeon.capshinsmg.workers.dev/?book=1&utm_source=meta&utm_medium=paid&utm_campaign=open_event&utm_content=poster_v2
```
- `book=1` = 랜딩 도착 즉시 예약 시트 자동 오픈 ("바로 신청" 약속과 착지 일치 — 이탈 최소화)
- 캠페인명을 `open_event`로 분리 → 관리자탭·픽셀에서 v1과 성과 구분

### 거는 법 (기존 캠페인에 추가)
1. 광고 관리자 → 기존 광고 세트 열기 → **광고 복제** → 이미지·텍스트·URL을 v2로 교체 (같은 세트 안에서 v1과 A/B — 메타가 잘 되는 쪽에 예산을 몰아줌)
2. 또는 전환이 급하면: **v1 광고 끄고 v2만 단독** 운영
3. 며칠 후 관리자탭 통계에서 `meta/paid` 방문 대비 예약 신청을 v1 대비 비교

## 3. 광고 세트 세팅

| 항목 | 값 |
|---|---|
| **캠페인 목표** | 초기: **트래픽**(랜딩 방문 최대화). 픽셀+예약(Schedule) 데이터 쌓이면 → **판매/전환**으로 전환 |
| **위치 타겟** | **안산시 + 공방 반경**(대면 리딩이므로 필수 — 01 §9). 핀 반경 최소~15km부터, 성과 보며 조정 |
| **관심사** | 타로 · 점성술 · 사주 · 운세 · 심리테스트 |
| **연령/성별** | 초기 넓게(예 18–45, 전체) → 인사이트 쌓이면 반응 좋은 층으로 좁힘 |
| **노출 위치** | 자동(Advantage+) 시작, 인스타 피드·스토리·릴스 중심 |
| **예산** | 소액 일예산으로 3~5일 학습 → CPC·랜딩 도달 보고 조정 |

## 4. 정책 체크 (리젝 방지 — 01 §8)

- ✅ 카피는 **행동 제안형**("확인해보세요", "뽑아보세요")
- ❌ 개인 속성 단정 금지 — "당신 요즘 힘들죠?", "당신의 불행" 류는 리젝 사유
- ✅ 운세는 "재미+참고용" 포지션. 의료·재정 단정 조언 금지
- ✅ 이미지 내 텍스트는 최소(현재 소재 OK) — 적을수록 도달 유리

## 5. 성과 측정 (운영 중)

- **랜딩 자체 집계**: 관리자탭 📈 통계 → 유입 경로에 `meta/paid` 행 → 방문 대비 예약 신청 비율 = 광고→예약 실측
- **픽셀(12단계 삽입 후)**: PageView·draw_start·ViewContent·InitiateCheckout·**Schedule**(최적화 목표) 이벤트로 메타 리포트와 교차 검증
- 두 수치를 대조해 소재/타겟을 다듬는다
