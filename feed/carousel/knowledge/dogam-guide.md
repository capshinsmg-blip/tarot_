# 묘연 타로 도감 — 캐러셀 제작 가이드 (SSOT)

> insta_design(insta-carousel-builder)의 방법론을 묘연 브랜드로 재구성한 것 (2026-07-15).
> 캐러셀 제작 시 이 파일이 단일 기준. 텍스트 수치·해석은 `app/js/cards-data.js`에서만 가져온다.

---

## 1. 7장 구조 공식 (planning/10 §3 확정)

| # | 역할 | 내용 | 레이아웃 |
|---|---|---|---|
| 1 | **Cover** | 카드 아트 + `0 · 광대` 타이포만 | 배경 + 카드 大 + 하단 타이틀 |
| 2 | 이 카드는 | 한 줄 정의(명조) + 키워드 칩 3개 | 중앙 정렬 텍스트 |
| 3 | 💘 연애 | 축약 해석 1~2문장 | 라벨 + 헤드라인 + 보조문 |
| 4 | 💰 금전 | 〃 | 〃 |
| 5 | 💼 일 · 진로 | 〃 | 〃 |
| 6 | 묘연이의 한 마디 | 캐릭터 + 조언 (말풍선) | 캐릭터 + 인용 |
| 7 | **CTA** | 카드 뒷면 + "오늘 당신에게 온 카드는?" | 뒷면 + CTA + 핸들 |

- 한 슬라이드 = 한 포인트. 본문(3~5)은 헤드라인 강조어 1개만 골드
- CTA는 7번에만 (본문에 저장/팔로우 유도 금지)

## 2. 디자인 DNA (변경 금지)

- 캔버스 1080×1350(4:5), 렌더 2x 레티나
- 팔레트: navy `#1A1F3D` · deep `#10142B` · gold `#E9B96E` · lilac `#A99BD6` · cream `#F6EFE3` — 이 5색 밖 금지
- 폰트: 헤드라인 **Gowun Batang 700** / 본문·라벨 Pretendard — `templates/base.css`의 클래스만 사용
- 배경: `assets/bg/bg_text.png` (힉스필드 생성 셀레스티얼 프레임 — 중앙 비움). 커버·CTA도 동일 배경 위에 구성
- 카드 아트: `design/cards/major/` **고해상 원본 PNG** 사용 (webp 아님)
- 여백 원칙: 상하 안전영역 90px+, 텍스트 최대 폭 860px, 꽉 찬 레이아웃 금지 (AI 티 남)

## 3. 텍스트 축약 규칙 (cards-data.js → 슬라이드)

- 원문 3~4문장 → **헤드라인 1문장 + 보조문 1문장**으로 축약. 새 주장 추가 금지 (해석 왜곡 방지)
- 헤드라인: 조언·비유 문장을 우선 발췌, 15~26자, 강조어 1개 `<span class="gold">`
- 보조문: 원문의 구체 행동 제안을 1문장으로
- 화법: 다정한 존댓말 유지, **단정 예언 금지** (`banned-words.json`의 fortune_absolutes)
- 정의(슬라이드 2): 카드의 핵심을 은유 1문장으로 (예: 광대 = "출발선의 카드")

## 4. 품질 킬라인 (발행 전 체크)

1. 7장 전부 1080×1350 렌더 확인
2. 텍스트 잘림·넘침 없음 (렌더 PNG 육안 검수 — Read로 각 장 확인)
3. 7장 배경·폰트·컬러 통일
4. Cover: 카드 번호·이름 외 텍스트 없음 (미니멀 유지 — 사용자 확정 컨셉)
5. 금칙어 0건 (`banned-words.json`)
6. 슬라이드 6의 조언은 cards-data.js `advice` 그대로 (창작 금지)
7. CTA 문구 고정: "오늘 당신에게 온 카드는?" + "프로필 링크에서 무료로 🌙" + `@myoyeon.tarot`

```

(카드 요약 2~3줄, 존댓말)
🔖 이 카드가 나올 때마다 찾아보게 저장해 두세요
🌙 오늘 당신의 카드는 프로필 링크에서 무료로
.
#타로 #타로카드 #오늘의운세 #타로해석 #메이저아르카나
#안산타로 #고잔동타로 #단원구타로 #안산데이트
```

## 6. 파일 구조 · 명령

```
feed/carousel/
├── render.js                  # HTML → PNG (puppeteer)
├── templates/base.css         # 디자인 토큰 (슬라이드가 ../../../templates/base.css 로 링크)
├── knowledge/                 # 이 가이드 + 금칙어
├── assets/bg/                 # 배경 (힉스필드 생성)
└── output/<NN_card>/
    ├── slides/slide-01~07.html
    ├── slide-01~07.png        # 완성본 (1080×1350)
    └── caption.txt

# 렌더: node feed/carousel/render.js --card 00_fool
# 슬라이드 HTML에서 저장소 루트 = ../../../../../ (5단계 위)
```
