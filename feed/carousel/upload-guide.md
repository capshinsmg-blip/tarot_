# 도감 캐러셀 업로드 가이드 — 본문글 · 해시태그 · 오디오

> 작성 2026-07-15. 도감 22장을 인스타에 올릴 때 매번 참조. 본문글은 각 카드 `output/<카드>/caption.txt`에 이미 완성돼 있고, 이 문서는 **오디오 선택 + 해시태그 로테이션 + 발행 요령**을 담는다.

---

## 1. 본문글 (caption)

- **이미 준비됨**: `output/<NN_카드>/caption.txt` — 훅 1줄 + 카드 요약 + 저장 유도 + 프로필 링크 안내가 들어있다. 복붙해서 쓰면 됨.
- **훅 살짝 바꿔 A/B**: 같은 카드를 나중에 재게시할 때 첫 줄(훅)만 바꾸면 새 게시물처럼 신선해진다. 훅 변형 예: 질문형("○○ 카드, 왜 무서운 카드가 아닐까요?") / 숫자형("타로 22장 중 유일하게 ○○한 카드") / 공감형("요즘 마음이 복잡하다면").
- **첫 댓글 활용**: 본문은 짧게, 해시태그는 **첫 댓글**에 몰아넣으면 본문이 깔끔하다(도달에는 차이 없음). 둘 중 편한 방식으로 통일.
- **CTA는 캡션 끝 고정**: "🌙 오늘 당신의 카드는 프로필 링크에서 무료로" — 바이오 링크(09단계 UTM)로 유입을 닫는다.

## 2. 오디오 — 계정 유형부터 확인 (중요)

인스타 **비즈니스/프로페셔널 계정**은 저작권 때문에 **상업용 음원 라이브러리만** 쓸 수 있다(대중가요 인기곡 상당수가 회색 처리되어 선택 불가). 크리에이터 계정은 폭이 조금 더 넓다.
→ 타로공방은 사업 계정이므로 **"이 오디오는 비즈니스 계정에서 사용할 수 없습니다" 표시가 뜨는 곡은 피하고**, 회색 아닌 음원 중에서 고른다. 대부분 잔잔한 lo-fi·앰비언트·연주곡은 사용 가능.

### 트렌딩 음원 고르는 법 (릴스/오디오 추가 화면)
1. 오디오 검색창에 아래 **무드 검색어**를 넣는다.
2. 곡 옆에 **↗ (상승 화살표)** 붙은 게 지금 뜨는 음원 → 도달에 유리.
3. **재생수 1만~50만** 정도의 "중간 크기" 트렌딩이 신인 계정엔 제일 좋다(수백만짜리는 이미 포화).
4. 마음에 든 음원은 오디오 페이지에서 **저장(북마크)** 해두고 다음 게시물에 재사용.

### 무드 검색어 (자정의 묘연 브랜드 톤)
`lofi` · `lo-fi chill` · `dreamy` · `ethereal` · `ambient piano` · `mystical` · `celestial` · `calm night` · `달밤` · `새벽감성` · `잔잔한 피아노` · `몽환` · `힐링`

### 카드 무드 → 오디오 4버킷
| 버킷 | 카드 | 오디오 결 |
|---|---|---|
| ☀️ 밝음·희망 | 태양·세계·별·연인·여황제·심판 | 몽환 dreamy, 따뜻한 피아노, 벅찬 앰비언트 |
| 🌙 신비·성찰 | 여사제·은둔자·달·매달린 사람·운명의 수레바퀴 | ethereal, 몽환 ambient, 신비 pad |
| ⚡ 역동·전진 | 마법사·전차·힘·태양(활력) | 리드미컬 lo-fi beat, 가벼운 그루브 |
| 🖤 전환·묵직 | 죽음·탑·악마·심판 | 시네마틱하지만 잔잔, 다크 lo-fi |
| 🍃 안정·조화 | 황제·교황·정의·절제 | 차분한 clean 피아노, 소프트 lo-fi |

## 3. 해시태그 — 로테이션 필수

**같은 해시태그 세트를 매 게시물에 그대로 쓰면 스팸 신호**로 도달이 깎인다. 아래처럼 **고정 + 카드별 + 지역 + 로테이션**을 조합해 매번 20개 안팎, 세트가 겹치지 않게 섞는다. 크기(대/중/소)를 섞어야 소형 태그에서 상위 노출을 노린다.

- **고정 코어 (매번, 5개)**: `#타로 #타로카드 #오늘의운세 #타로해석 #메이저아르카나`
- **카드별 (2~3개)**: §5 표의 카드 태그 — 카드마다 다르니 자동 로테이션 효과
- **지역 (3~4개, 예약 유입 핵심)**: `#안산타로 #고잔동타로 #단원구타로 #안산데이트 #안산` 중 매번 3~4개 골라 섞기
- **로테이션 풀 (아래에서 매번 5~7개 다르게 선택)**:
  `#데일리타로 #타로그램 #타로점 #운세 #오늘의타로 #타로상담 #고양이타로 #묘연 #타로스타그램 #감성타로 #힐링타로 #마음챙김 #타로카드해석 #안산타로공방 #경기타로`

## 4. 발행 요령

- **묶음 발행 대신 데일리 1장**: 22장을 하루에 몰지 말고 하루 1~2장씩 꾸준히. 계정이 "매일 뜨는 곳"으로 학습된다(랜딩의 '하루 1장' 컨셉과도 일치).
- **시간대**: 타깃이 폰 보는 저녁 8~11시 / 출근 8~9시 권장. 인사이트 쌓이면 팔로워 활동 시간에 맞춰 조정.
- **커버(1장)가 전부**: 피드 썸네일 = 슬라이드 1. 이미 카드 아트 대문이라 스크롤 정지력 좋음.
- **순서**: 0 광대 → 21 세계 순서 강제 아님. 반응 좋을 카드(태양·연인·별·죽음)를 앞쪽에 배치해 초반 도달을 끌어올려도 됨.
