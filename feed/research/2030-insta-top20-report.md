# 2030 인스타 반응 상위 콘텐츠 분석 → 타로 콘텐츠 적용 보고서

> 작성 2026-08-24 · 도구: Apify `instagram-hashtag-scraper` (2회 실행, ~$0.6)
> 목적: 카테고리 무관 2030 고반응 게시글의 **콘텐츠 종류·키워드·미디어 패턴**을 뽑아 묘연 타로 콘텐츠 기획에 적용

---

## 0. 방법론 (정직 고지)

- 인스타에는 "2030 전체 인기 랭킹" API가 없다 → **2030이 주로 소비하는 해시태그 8종의 '인기(Top)' 섹션**을 프록시로 수집:
  `#일상 #유머 #연애 #심리테스트 #자기계발 #직장인 #카페추천 #운세`
- 수집량: **포스트(이미지·캐러셀) 148개 + 릴스 100개 = 248개**
- 참여점수 = 좋아요 + 3×댓글 (릴스는 +0.1×조회수) — instagram-research 스킬 공식
- 포스트와 릴스는 **점수 스케일이 달라 분리 랭킹** (릴스는 조회수 때문에 통합 시 전부 릴스가 됨)
  → "상위 20" = **포스트 TOP 10 + 릴스 TOP 10**
- 한계: 인기 섹션은 당일성 강함(스냅샷 2026-08-24), 좋아요 숨김 28건(댓글 가중으로 보정), 연령은 해시태그 소비층 기반 추정

## 2. 분석 A — 콘텐츠 종류

| 발견 | 수치 | 의미 |
|---|---|---|
| 포스트는 **캐러셀이 지배** | 전체 71% (105/148), TOP20 중 13 | 넘기게 만드는 구조(질문→결과)가 체류·저장을 만든다 |
| 릴스 상위는 **3~12초 초단편** | TOP10 중 8개 (전체 중앙값 31s) | 짧을수록 루프 재생 → 조회수 증폭 |
| 콘텐츠 장르 | 심리테스트·운세가 상위 20 중 **11개** | 참여형(내 얘기) > 시청형(남 얘기) |
| 나머지 장르 | 이슈 요약 6 · 자기계발/책 3 | "요약해주는 계정"도 강함 |

## 3. 분석 B — 메인 키워드·캡션 공식

- **키워드 빈도(캡션)**: 운세(23) 사주(21) 유머(22) 자기계발(22) 심리테스트(19) 직장인(19) … + 테스트/성향/MBTI 계열
- **해시태그 상위**: #유머 #자기계발 #심리테스트 #운세 #직장인 #사주 #성격테스트 #오늘의운세 #띠별운세 #MBTI #타로
- **이기는 캡션 공식** (TOP20 평균 454자 — 전체 288자보다 김):
  1. **질문 훅**: "너는 몇 번이야?", "너넨 뭐 나옴?", "몇 점인가요?"
  2. **댓글 CTA**: "댓글에 [번호] 남겨" / "공감되면 저장🔖" / "찬성 vs 반대?"
  3. **결과를 캡션 하단에 길게** ("결과는 아래에👇") → 더보기 클릭 + 체류
  4. 이모지 앵커(👇🔮✅😱) + 반말·구어체 (2030 톤)

## 4. 분석 C — 이미지·동영상 (썸네일 육안 검수 포함)

**이미지/캐러셀**
- **텍스트가 화면의 30~60%** — 제목이 곧 썸네일 (그림은 배경)
- 두 부류: ① 다크 미스틱(어두운 배경+타로카드+수정구+흰/보라 볼드 타이포 — 5위) ② 초저제작(집중선/스톡 이미지+검정·빨강 초대형 텍스트 — 릴스4위 커버)
- 운세 5위 커버 구조: 상단 여백 → 소재 이미지 → **하단 좌측 2줄 헤드라인** ("8월 24일~30일 / 이번 주 나의 운세는?")

**동영상(릴스)**
- 상위권은 사실상 **"움직이는 이미지"** — 정지 화면+텍스트에 가벼운 모션, 3~12초 루프
- 음원: original audio 57%, 나머지는 잔잔·스피드업 팝 (음원 의존도 낮음 — 텍스트 훅이 본체)
- 구조: 질문 1장 → (선택지) → "결과는 캡션/댓글로" — **영상 안에서 결과를 안 줌** (참여 강제)

## 5. 이기는 공식 5줄 요약

1. **"X로 알아보는 Y"** 투사 테스트 (과자→MBTI, 가방→무의식, 별→외로움)
2. **선택 1번 시키고 결과는 딴 데**(캡션·댓글·DM)에 둔다 → 댓글 폭발
3. **3~12초 릴스 + 캐러셀** 두 형식이 조회·저장을 각각 담당
4. 텍스트-퍼스트 비주얼 (제작비보다 훅 문장)
5. 오가닉 감성 유지 (광고 티 나면 죽음)

## 6. ★ 타로 적용 — 묘연 콘텐츠 기획 6안

> 핵심 통찰: **2030 인기 콘텐츠의 왕좌(심리테스트·카드고르기)가 바로 우리 업종이다.** 남의 장르를 흉내낼 필요 없이, 우리 것을 '그들의 형식'으로 포장하면 된다. 기존 자산(카드 22장·묘연이·릴스 뱅크·랜딩)과 전부 연결됨.

| # | 기획 | 형식 | 벤치마크 | 묘연 실행 |
|---|---|---|---|---|
| 1 | **"끌리는 카드 하나 고르세요"** 주간 시리즈 | 캐러셀 (커버=뒷면 3~4장) | 5위·17위 | 커버: 카드 뒷면+질문 → 슬라이드: 카드별 해석 → 마지막: "더 깊은 답은 프로필 링크 🌙". 댓글 CTA "고른 번호 남겨줘" |
| 2 | **초단편 카드고르기 릴스 (5~8초)** | 릴스 | 릴스 2·3·7위 | 뱅크 B5(카드 부채)+텍스트 훅 "이번 주 너에게 필요한 건?" → 결과는 캡션에 유형별 해석 (release는 build-reel.mjs로 0크레딧) |
| 3 | **"X로 알아보는 Y" 타로 버전** | 릴스 3~5초 | 릴스 4위 | "자주 뽑는 카드로 알아보는 연애 스타일" / "생일 숫자로 보는 나의 메이저 카드" — 과몰입 공식 이식 |
| 4 | **감성 일일운세 텍스트 카드** | 캐러셀 | 2위 the.saju | 묘연이 톤의 위로 문장 1장 + 오늘의 카드 1장 + 긴 감성 캡션. 도감 base.css 재활용 |
| 5 | **날짜 박힌 주간운세 커버** | 캐러셀 | 5위 | "8/25~8/31 이번 주 나의 흐름은?" — 날짜가 신선도 신호 → 매주 월요일 고정 발행 |
| 6 | **참여형 질문 이미지** | 단일 이미지 | 11·13위 | "타로 볼 때 제일 궁금한 건? 💘연애 vs 💰돈" 초저제작 텍스트 카드 — 댓글 유도용 막간 콘텐츠 |

### 발행 리듬 제안 (기존 캘린더에 얹기)
- 월: 기획5 (주간운세 캐러셀) — 도감과 격주 교차
- 수: 기획2/3 (초단편 릴스) — 기존 릴스 뱅크 조합
- 금: 기획1 or 6 (참여형)
- **모든 결과 해석의 끝은 동일 CTA**: "오늘의 카드는 프로필 링크에서 무료로 🌙" (→ 랜딩 → 5,000원 예약 퍼널)

### 하지 말 것 (상위권이어도 모방 금지)
- 1위 "로또 횡재운, 댓글 남기면 비법 전수" 류 — **단정 예언+현혹**이라 메타 광고정책·브랜드 톤(01 §8) 위반. 묘연은 제안형 화법 유지
- DM 강제 유도(5위의 "팔로우 안 하면 DM 안 감")는 어그로성 — 우리는 링크 인 바이오로 대체

## 7. 측정

- 각 기획 첫 2주: 인스타 인사이트(도달·저장·댓글) + 관리자탭 `instagram/bio` 유입 변화
- 기획별 캡션 끝 해시태그는 upload-guide 로테이션 규칙 적용
- 반응 상위 형식에 3주차부터 발행 비중 몰기
