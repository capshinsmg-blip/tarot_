# 03. 브랜드컬러 설정

> 작성일: 2026-07-14 · 상태: **v1 확정 — A안 "자정의 묘연" (2026-07-14)**

---

## 1. 컬러 무드 정의 (02 컨셉에서 상속)

> "깊은 밤 + 따뜻한 빛" — 어둡지만 무섭지 않고, 귀엽지만 가볍지 않게.

- 다크 베이스: 신비와 전문성(예약 신뢰)을 컬러가 담당
- 웜 포인트: 친근함과 CTA 시인성 담당
- 친근함의 본체는 캐릭터(5단계)가 담당하므로, 컬러는 신비·신뢰 쪽에 무게를 둬도 된다

## 2. 컬러 역할 체계 (5 롤)

| 롤 | 쓰임 |
|---|---|
| 베이스 | 랜딩 배경, 피드 기본 배경, 광고 배경 |
| 딥 | 그림자, 보조 배경, 카드 뒷면 바탕, 포인트 위 텍스트 |
| 포인트 | CTA 버튼, 강조 요소, 행운 요소 하이라이트 |
| 서브 | 보조 장식, 일러스트 라인, 캡션 텍스트 |
| 크림 | 본문 텍스트(다크 위), 카드 앞면 바탕 |

## 3. 시안 3종

### A. 자정의 묘연 — 미드나잇 네이비 + 문 골드 (추천)

| 롤 | HEX | 색 |
|---|---|---|
| 베이스 | `#1A1F3D` | 미드나잇 네이비 |
| 딥 | `#10142B` | 자정 네이비 |
| 포인트 | `#E9B96E` | 문 골드 |
| 서브 | `#A99BD6` | 라일락 |
| 크림 | `#F6EFE3` | 문라이트 크림 |

- 강점: 골드 CTA의 시인성 최상급, 고급감으로 예약 신뢰 보완, 보라+금 일색의 타로 광고들 사이에서 네이비 베이스로 차별화
- 약점: 3안 중 가장 클래식 — 캐릭터가 충분히 귀여워야 균형이 맞음

### B. 황혼의 살구 — 더스크 퍼플 + 피치

| 롤 | HEX | 색 |
|---|---|---|
| 베이스 | `#2B2144` | 황혼 퍼플 |
| 딥 | `#1D1631` | 딥 퍼플 |
| 포인트 | `#F2A08D` | 살구 피치 |
| 서브 | `#C9B9EC` | 라이트 라일락 |
| 크림 | `#FBF2E8` | 피치 크림 |

- 강점: 3안 중 가장 따뜻하고 친근함, 2030 여성 타겟 감성 적중률 높음, 스토리 공유 이미지가 부드럽게 예쁨
- 약점: 퍼플 베이스는 기존 타로 브랜드와 색군이 겹침 (톤으로 차별화해야 함)

### C. 깊은 숲의 새벽 — 딥 틸 + 캔들 앰버

| 롤 | HEX | 색 |
|---|---|---|
| 베이스 | `#14383A` | 딥 틸 |
| 딥 | `#0C2426` | 심야 숲 |
| 포인트 | `#F0A64F` | 캔들 앰버 |
| 서브 | `#9FC6B2` | 세이지 민트 |
| 크림 | `#F7F1E1` | 웜 아이보리 |

- 강점: 타로 씬에서 거의 안 쓰는 색군 — 차별화 최상, "숲속 밤의 공방" 세계관 확장 가능
- 약점: '달·밤' 키워드와의 직관적 연결이 네이비/퍼플보다 약함

## 4. 적용 가이드 (확정 후 전 단계 공통 적용)

| 접점 | 적용 |
|---|---|
| 랜딩페이지 | 베이스 배경 + 크림 텍스트 + 포인트 CTA (다크 단일 테마) |
| 카드 뒷면(6단계) | 딥 바탕 + 서브 라인 문양 + 포인트 심볼 |
| 인스타 프로필/피드 | 베이스 톤으로 그리드 통일, 포인트는 면적 10~20%만 |
| 공유 이미지(9:16) | 베이스 배경 + 카드 아트 + 크림 텍스트 + 하단 핸들 |
| 메타 광고 | 포인트 컬러 CTA 버튼 시인성 기준으로 소재 제작 |

- 명도 대비: 포인트/크림 ↔ 베이스·딥 간 대비는 모두 WCAG AA(4.5:1) 이상으로 유지
- 포인트 컬러 남용 금지: 화면당 포인트 면적 20% 이내 — CTA가 항상 가장 밝은 요소여야 함
