## 1. 캐릭터 프로필

| 항목 | 설정 |
|---|---|
| 이름 | **묘연이** (공방명과 동일 — 브랜드 = 캐릭터 일체화) |
| 종 | 고양이 (품종 불특정, 둥근 실루엣의 단모) |
| 역할 | 오늘의 카드를 건네주는 밤의 안내자 |
| 성격 | 다정하고 조금 능청스러움. 낮에는 낮잠, 밤에 활동. 손님의 이야기를 끝까지 들어줌 |
| 세계관 | 자정의 공방에서 카드를 고르고, 아침이 되면 손님에게 "오늘의 카드"를 배달한다 |

## 2. 외형 스펙 (브랜드컬러 매핑 — 03 팔레트 고정)

| 부위 | 컬러 | HEX |

| 그림자·무늬 | 자정 네이비 (딥) | `#10142B` |

- 시그니처: 목의 **금색 초승달 펜던트** + 앞발로 **카드 한 장을 건네는 포즈**
- 실루엣 원칙: 둥글둥글, 뾰족한 요소 최소화 (친근함 담당은 캐릭터라는 03 원칙)

## 3. 말투 가이드 (모든 접점 공통)

- 기본: 다정한 존댓말 — "오늘의 카드를 가져왔어요"
- 포인트: 문장 끝 "냥"은 **가끔만** (피드 캡션 등 가벼운 접점 한정, 랜딩 결과 해석에서는 사용 안 함 — 신뢰 훼손 방지)
- 금지: 단정적 예언("반드시 ~된다"), 겁주는 표현, 의료·재정 단정 조언 (01 §8 연동)

## 4. 비주얼 스타일 (3안 생성 → 선택)

| 안 | 스타일 | 강점 | 주 용도 적합성 |

| B | 소프트 스토리북 | 감성적, 밤 무드 표현력 최고 | 피드·공유 이미지·광고 |
