## 2. 화면 플로우 (01 §3 구현)

```
S1 히어로 → S2 카테고리 4택1 → S3 셔플+스프레드+선택 → S4 플립 리빌+결과 → (예약 시트)
```

### 모션 사양 (사용자 요구 반영)

| 구간 | 모션 |
|---|---|
| S3 셔플 | 중앙 덱이 좌우로 카드를 섞는 애니메이션 ~1.2초 |
| S3 스프레드 | 뒷면 카드 22장이 덱에서 부채꼴 스트립으로 펼쳐짐 (staggered slide, 카드별 딜레이) |
| S3 선택 | **가로 터치 스크롤** 스트립 — 원하는 카드를 스크롤로 찾아 **탭 1번**으로 선택 (모바일 터치 퍼스트) |
| S4 리빌 | 선택 카드가 중앙 확대 → 3D 플립(rotateY 0.9s) + 골드 글로우 펄스 + 별 파티클 버스트 |
| S4 결과 | 카드명 → 키워드 → 해석 → 행운 → CTA 순 staggered fade-in |

## 3. 콘텐츠 원칙 (해석 텍스트)

- **정확성**: 라이더-웨이트 전통 해석(웨이트 『Pictorial Key to the Tarot』 계열 정방향 의미)을 기준으로 작성. 카드 간 의미 뒤섞임 금지 — 작성 후 카드별 교차 검수
- **분량**: 카드 22장 × 카테고리 4종(연애/금전/일·성장/총운) = 88개 해석, 각 3~4문장
- **문체**: 다정한 존댓말, 단정 대신 제안형 (01 §8, 05 말투 가이드). AI 상투 어미 반복 금지, 카드 장면 묘사를 해석에 녹임
- **구조**: 상황 진단 → 구체적 조언 → 여운/격려 + 행운 컬러·아이템 + 묘연이의 한 마디
- 역방향(리버스)은 사용하지 않음 — 오늘의 운세 표준 포맷

## 4. 핵심 로직

- **하루 1회 고정**: `localStorage`에 `{날짜, 카드, 카테고리}` 저장. 같은 날 재방문 → 아침 결과 재노출 + "오늘의 카드는 이미 도착했어요" 배너. 자정 리셋
- **공유 이미지**: Canvas로 9:16 (1080×1920) 이미지 생성 — 카드 아트 + 키워드 + `@myoyeon.tarot` 워터마크 → 저장 버튼
- **메타 픽셀**: `PIXEL_ID` 플레이스홀더 + 이벤트 스텁 (PageView / draw_start / ViewContent / InitiateCheckout). 12단계에서 실제 ID 삽입
- **예약 CTA**: 결과 화면 하단 고정 버튼 → v1은 인스타 DM 안내 바텀시트 (InitiateCheckout 이벤트 발화)
- **오픈 이벤트 팝업 (2026-08-03 추가, 광고 전환 개선)**: 결과 확인 3.2초 뒤 묘연이 팝업 — "오픈 기념 · 1:1 타로리딩 단돈 5,000원" → [지금 예약하기] = 예약 시트 직행. 하루 1회(localStorage `myoyeon_evpop_v1`), 예약 시트·공유 모달 열려 있으면 미노출. `popup_view`/`popup_click` 이벤트로 효과 측정 (문구 수정: `app/js/booking.js`의 showEventPopup)
