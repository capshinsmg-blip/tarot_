# 10. 피드 컨텐츠 기획

> 작성일: 2026-07-15 · 상태: **v1 확정 — 라이트 리듬(주 2~3피드 + 데일리) · 도감 0번부터 순차 (2026-07-15)**

---

## 1. 피드의 역할 (퍼널 안에서)

| 역할 | 설명 |
|---|---|
| 팔로우 전환 | 광고·랜딩에서 온 사람이 프로필을 눌렀을 때 "실재하는, 살아있는 공방"으로 보여야 팔로우함 (01 서브플로우 B) |
| 신뢰 보완 | 네이버 플레이스 부재(02 결정) → **후기·공방 콘텐츠가 예약 신뢰의 대체 축** |
| 무료 유입 | 릴스 오가닉 도달 → 랜딩 유입 (광고비 0의 유입 라인) |
| 리텐션 | 오늘의 카드 데일리 → 팔로워의 재방문 습관 유지 → 예약 리드 풀 |

## 2. 콘텐츠 필러 4개

| 필러 | 포맷 | 목적 | 피드 비중 |
|---|---|---|---|
| **A. 묘연 타로 도감** | 캐러셀 (사용자 확정 컨셉) | 저장 유도 · 그리드 브랜딩 · 전문성 | ~40% |
| **B. 묘연이 릴스** | 릴스 (AI 제작) | 도달 · 랜딩 유입 | ~30% |
| **C. 오늘의 카드** | 스토리 (매일) | 리텐션 · 링크 클릭 | 데일리 (피드 외) |
| **D. 신뢰 콘텐츠** | 피드 + 스토리 | 후기 · 공방 실재감 → 예약 전환 | ~30% |

## 3. 필러 A — 「묘연 타로 도감」 캐러셀 ★ 사용자 확정 컨셉

> 커버 = 고양이 카드 아트 + 번호·이름만. 뒤 슬라이드 = 연애/금전/진로별 의미 풀이.

### 슬라이드 구성 (7장, 4:5 = 1080×1350)

| # | 슬라이드 | 내용 |
|---|---|---|
| 1 | 커버 | 카드 아트 풀블리드 + 하단 미니멀 타이포 `XVIII · 달` (그 외 텍스트 없음) |
| 2 | 이 카드는 | 핵심 키워드 3개 + 한 줄 정의 |
| 3 | 💘 연애에서 나오면 | 1~2문장 풀이 |
| 4 | 💰 금전에서 나오면 | 1~2문장 풀이 |
| 5 | 💼 일·진로에서 나오면 | 1~2문장 풀이 |
| 6 | 묘연이의 한 마디 | 캐릭터 + 조언 한 줄 (말풍선) |
| 7 | CTA | 카드 뒷면 아트 + "오늘 당신에게 온 카드는? 프로필 링크에서 무료로 🌙" |

### 제작 원칙

- **텍스트는 새로 쓰지 않는다** — 랜딩 `cards-data.js`의 88개 해석·키워드·조언을 캐러셀용으로 축약(1~2문장). 랜딩과 피드의 톤이 자동으로 일치하고, 제작 속도가 3배 빨라짐
- 그리드 전략: 22장이 순서대로 쌓이면 **"덱이 완성되어 가는 계정"** — 그리드 자체가 브랜딩이 됨
- 커버 타이포 규칙: 카드 아트를 가리지 않게 하단 안전영역만 사용, 골드 세리프 (03 팔레트)

### 캡션 템플릿

```
(훅 한 줄 — 예: "타로에서 제일 오해받는 카드예요")
(카드 요약 2~3줄)
🔖 이 카드가 나올 때마다 찾아보게 저장해 두세요
🌙 오늘 당신의 카드는 프로필 링크에서 무료로
.
#타로 #타로카드 #오늘의운세 #타로해석 #메이저아르카나
#안산타로 #안산타로맛집 #고잔동타로 #단원구타로 (지역 — 대면 전용이라 필수)
```

- 발행 페이스: **주 1~2장 (라이트 여력 기준) → 22장 = 약 3~5개월 시리즈** (광고 집행 기간 내내 피드가 계속 자람 — 길어지는 건 단점이 아니라 지속 콘텐츠 확보)
- 발행 순서: ✅ **0번(광대)부터 순차** — 그리드에 덱이 순서대로 완성되는 "도감 서사". 유명 카드(달·별·태양)는 릴스 R1 소재로 초반에 배치해 훅을 보완

## 4. 필러 B — 묘연이 릴스 (AI 제작) ★ 사용자 확정 방향

> 묘연이가 메인으로 타로 정보를 전하고, 마지막엔 랜딩으로 흘려보내는 영상.

### 포맷 3종

| 포맷 | 길이 | 내용 | 역할 |
|---|---|---|---|
| **R1 묘연이의 타로상식** | 30~40초 | 오해 깨기·흥미 소재를 3포인트로 (아래 소재 뱅크) | 정보성 도달 + 팔로우 |
| **R2 카드 한 장 뽑고 가세요** | 10~15초 | 뒷면 카드 3장 → 직관으로 1장 선택 → "고른 카드의 답은 프로필 링크에서" | **랜딩 유입 직결** |
| **R3 자정의 공방 무드** | 7~10초 | 묘연이 애니메이션 루프 + 공방 감성 + BGM | 가벼운 도달·브랜딩 |

### R1 소재 뱅크 (초기 10개)

1. 죽음 카드가 나오면 오히려 좋아해야 하는 이유
2. 타로는 미래를 '맞히는' 게 아니에요 — 그럼 뭘 하는 걸까
3. 연애 리딩에서 가장 자주 나오는 카드 3장
4. 탑 카드가 무너뜨리는 건 '어차피 무너질 것'뿐
5. 타로 처음 볼 때 하면 안 되는 질문 유형
6. 달 카드가 말하는 불안의 정체
7. 같은 카드가 자꾸 나오는 게 우연이 아닌 이유
8. 별 카드가 '희망'인 진짜 이유 (원작 상징 풀이)
9. 리딩 전에 질문을 정리하면 좋은 이유
10. 22장 중 가장 행운의 카드는? (태양 카드 딥다이브)

### 공통 규칙

- **훅 1.5초**: 첫 컷에 결론/반전 문장 ("죽음 카드, 사실 좋은 카드예요")
- **엔딩 CTA 컷 고정**: 묘연이 + "오늘의 카드는 프로필 링크에서 무료로 🌙" — 모든 릴스 동일 (브랜드 각인 + 유입 동선)
- 캡션 첫 줄에도 CTA, 화법은 단정 금지 (01 §8 메타 정책 톤 그대로)
- 제작 파이프라인(11단계에서 파일럿으로 검증): 캐릭터·카드 이미지 → Higgsfield 이미지 투 비디오 + 한글 자막 오버레이 + BGM. 캐릭터 일관성은 `myoyeon_main` job 레퍼런스 고정으로 유지
- 측정: 릴스 → 프로필 → 바이오 링크 = `instagram/bio`로 관리자 통계에 잡힘 (9단계). 릴스 성과 자체는 인스타 인사이트(조회·평균 시청·프로필 방문)로

## 5. 필러 C — 오늘의 카드 스토리 (데일리)

- 매일 아침 정해진 시간(권장 8시)에 스토리 1장: 묘연이가 오늘 고른 카드 + **링크 스티커** (`utm_medium=story` — 9단계 링크 맵)
- 제작 1분 컷: 랜딩의 9:16 공유 이미지 포맷 재활용
- [오늘의 카드] 하이라이트에 아카이브 → 프로필 방문자의 첫 체험 콘텐츠

## 6. 필러 D — 신뢰 콘텐츠 (후기 · 공방)

- **후기**: 리딩 후 동의받은 후기(DM·카톡 캡처)를 브랜드 템플릿에 얹어 발행 (이름·사진 가림). 리딩 완료 → 후기 요청 → 콘텐츠화 파이프라인 (01 §5 운영 플로우의 마지막 고리)
- **공방**: 멜로우스페이스 공간, 리딩 준비, 실물 덱, 묘연이 굿즈 등 "실재하는 공방" 신호
- **예약 오픈 공지**: 관리자탭에서 시간표 열 때 스토리 공지 → 예약 촉진 루틴화

## 7. 그리드 · 톤 운영

- 카드 도감이 그리드의 기둥 — 릴스 커버도 네이비+골드 톤으로 통일
- 규칙: **팔레트(03) 밖의 색이 그리드에 들어오는 건 후기·공방 실사뿐** (실사가 오히려 포인트가 됨)
- 광고 시작(12단계) 전 최소 채움 목표: **피드 9개(그리드 3줄) + 릴스 3개 + 하이라이트 4종 + 데일리 스토리 가동**

## 8. 주간 발행 캘린더 (✅ 라이트 리듬 확정)

| 요일 | 콘텐츠 |
|---|---|
| 월 | 카드 도감 캐러셀 (0번부터 순차) |
| 수 | 릴스 (R1·R2·R3 로테이션) |
| 금 | 여력 있을 때: 도감 1장 더 or 신뢰 콘텐츠 (후기 생기면 후기 우선) |
| 매일 | 오늘의 카드 스토리 (아침 8시 권장, 1분 컷) |

- 원칙: 무리해서 채우지 않는다 — **거르는 주가 생겨도 데일리 스토리만은 유지** (계정이 살아있다는 신호는 스토리가 만든다)
- 예약 오픈 공지 스토리는 시간표 열 때마다 수시
